📦 Stock2Door — Australian Inventory & Fulfillment Platform
A modern, conversion-focused web platform built for Stock2Door, an Australian fulfillment service trusted by 500+ eCommerce brands. The site covers their full offering — warehousing, professional packing, eBay order management, and fast delivery across Australia.
🔗 Live Site: stock2door.netlify.app

✨ Features

Clean, professional UI targeting Australian eCommerce businesses
Fully responsive across mobile, tablet, and desktop
Services showcase — warehousing, packing, fulfillment, and eBay management
Trust-building sections (500+ brands, testimonials, key stats)
Strong CTAs optimized for lead generation
Fast load times with optimized assets
Deployed on Netlify

🚀 Getting Started
Clone the repo
bashgit clone https://github.com/fahadnajam1/stock2door.git
cd stock2door
Install dependencies
bashnpm install
Start dev server
bashnpm run dev
Then open http://localhost:5173 in your browser.

🌍 Deployment
Hosted on Netlify with auto-deploy from the main branch.
To deploy your own fork:

Push to GitHub
Import the repo into Netlify
Set build command: npm run build
Set publish directory: dist
Hit deploy
